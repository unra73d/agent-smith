# agent-smith — project instructions

Go desktop/server app (webview UI). Spec-driven development runs through
OpenSpec; tickets live in Jira; canonical specs live in Confluence.

## Entry points

- `/implement <JIRA-KEY>` — the main local workflow. Reads the ticket, explores,
  proposes a spec delta, waits for your approval, implements, and commits to a
  feature branch. Asks you whenever something is unclear.
- `/opsx:propose`, `/opsx:apply`, `/opsx:explore`, `/opsx:update`,
  `/opsx:archive`, `/opsx:sync` — the raw OpenSpec operations (generated by
  `openspec init --tools claude`), if you want to drive a single step by hand.

Subagents, dispatched by the workflow rather than invoked by hand: `explore`
(read-only code mapping), `coder` (executes `tasks.md`), `spec-hydrator`
(Confluence → `openspec/specs/`; the only agent that writes the baseline).

## Rules

- **`openspec/specs/` is the canonical baseline — do not hand-edit it.** It is
  produced by `openspec archive` or hydrated from Confluence by `spec-hydrator`.
  Spec changes go into deltas under `openspec/changes/<KEY>/specs/` via
  `openspec-propose`. Writes to `openspec/specs/` deliberately prompt for
  approval.
- **Jira is read-only from this session.** Reading issues is fine; commenting,
  transitioning, assigning, and creating are blocked. Moving a ticket is the
  developer's call.
- **Never push or open a PR unprompted.** Commit locally to `feature/<KEY>`,
  then offer. Work on `main` is not allowed.
- **Never launch a nested agent CLI** (`claude`, `opencode`, `make dev`,
  `make init_spec`) from Bash. Delegate with the Task tool instead.

## Checks

Keep the build green: `go build ./...`, `go vet ./...`, `go test ./...`.

## Credentials

The Atlassian MCP server (`@xuandev/atlassian-mcp`) is launched through
`@dotenvx/dotenvx`, which injects the gitignored `.env`. It needs exactly three
vars — `ATLASSIAN_DOMAIN`, `ATLASSIAN_EMAIL`, `ATLASSIAN_API_TOKEN` — plus
`CONFLUENCE_PARENT_ID` for spec hydration. See `.env.example`; `make check`
verifies them.
